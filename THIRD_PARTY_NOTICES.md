# Third-party notices

Fission Evolved is an unofficial community addon built for the GregTech: New Horizons ecosystem.

## Upstream projects

- [GregTech 5 Unofficial](https://github.com/GTNewHorizons/GT5-Unofficial) supplies the machine, recipe, fuel-rod, texture and energy APIs used by this project. GT5U is distributed under LGPL-3.0-or-later.
- [GTNH ExampleMod](https://github.com/GTNewHorizons/ExampleMod1.7.10) supplies the original Gradle project structure and shared GTNH build workflow.
- [Twist Space Technology](https://github.com/Nxer/Twist-Space-Technology-Mod), [GT Not Leisure](https://github.com/ABKQPO/GT-Not-Leisure), and [NH Utilities](https://github.com/Keriils/NH-Utilities) are optional integrations. Their code and JAR files are not bundled with this repository or release artifact.

## Visual assets

Fission Evolved's finished controller, casing, and fuel textures include original artwork as well as recolored or adapted visual elements designed to match GTNH/GT5U and TecTech machinery. Portions derived from an upstream asset remain subject to that asset's original license and attribution requirements; the repository's MIT license applies only to material authored for Fission Evolved.
